# 🎮 Восстановление картинок Roblox

**Утилита для Windows**, которая одним нажатием восстановляет все картинки!

![Скриншот](screenshot.png)

---

## ✨ Возможности

- 🔧 **Восстановить** - востановить все картинки!.
- 🔄 **Удалить изменение** — удаляет все изменение.
- 🖼️ **Удобный интерфейс** попробуйте сами!

---

## ⚙️ Системные требования

- **Windows 10/11** (только x86/x64)
- **Windows 7/8** (только x86/x64) (Программа запускается но роблокс не подерживается!)
- Права администратора
---

## 🚀 Установка и запуск

Запустить `.exe` для востановление картинок!
Скачайте последнюю версию в разделе **Releases**!
