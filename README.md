# 🎮 Восстановление картинок Roblox

**Утилита для Windows**, которая одним нажатием востанавляет все картинки!

![Скриншот](screenshot.png)

---

## ✨ Возможности

- 🔧 **Восстановить** - востановить все картинки!.
- 🔄 **Удалить изменение** — удаляет все изменение.
- 🖼️ **Удобный интерфейс** попробуйте сами!

---

## ⚙️ Системные требования

- **Windows 7/8/10/11** (только x86/x64)
- Права администратора
