# 🎮 Восстановление картинок Roblox (Hosts Fix)

**Утилита для Windows**, которая одним нажатием изменяет системный файл `hosts`, добавляя или удаляя запись для Roblox.  
Закрывает все процессы Roblox перед применением изменений и автоматически завершает свою работу, чтобы вы могли сразу запустить игру.

![Roblox Fix](local/roblox.png)

---

## ✨ Возможности

- 🔧 **Восстановить** — добавляет в `hosts` строку `18.65.39.105 tr.rbxcdn.com` (обходит блокировки/проблемы с картинками).
- 🔄 **Отменить** — возвращает исходный файл `hosts` без этой записи.
- ⏹️ **Автоматическое закрытие Roblox** — перед записью убивает все процессы `Roblox*.exe`.
- 🖼️ **Красивый интерфейс** с картинкой Roblox и иконкой приложения.
- 🛡️ **Запрос прав администратора** — при запуске, если прав нет, предложит перезапуститься с ними.

## ⚙️ Системные требования

- **Windows 7/8/10/11** (только x86/x64)
- Права администратора (для записи в `C:\Windows\System32\drivers\etc\hosts`)
- Установленный **Python 3.7+** (если собираете из исходников)

---

## 🚀 Установка и запуск

### 1️⃣ Готовый `.exe` (для пользователей)
Скачайте последнюю версию в разделе **Releases** или из папки `dist` в репозитории.  
Просто запустите `main.exe` и согласитесь на права администратора.

### 2️⃣ Из исходников (для разработчиков)

```bash
git clone https://github.com/ваш-логин/roblox-hosts-fix.git
cd roblox-hosts-fix
pip install pillow pyinstaller
python main.py
